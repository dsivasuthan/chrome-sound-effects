# Browser Effects


> ### **This is the closest version to the original Chrome Sound Effects, the main branch will be used for future updates, adding features while i'll be locking this up as a baseline for me or anyone who'll need it.**


Add sound effects to events triggered by user in Chromium Browsers(Chrome, Brave, Opera), like switching tabs, creating tabs, etc.

Based on the original work of dsivasuthan's chrome-sound-effects:

* https://github.com/dsivasuthan/chrome-sound-effects
