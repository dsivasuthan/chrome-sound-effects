# Chrome-Sound-Effects
Add sound effects to events triggered by user in Chrome, like switching tabs, creating tabs, etc.

Updated for Manifest V3 with a service worker and offscreen document for audio playback.

Custom sounds: Open the extension popup/options, upload an audio file for any sound entry. The audio is stored locally and overrides the default mapping. Click Clear to revert.
